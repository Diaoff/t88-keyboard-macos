# T88 私有 HID 协议说明

本驱动通过厂商私有 HID 报表控制键盘。本文记录**已在本机实际收发验证**的报文格式，
未验证的命令一律不实现（见 §4）。

## 1. 两种连接形态

T88 的配置通道随连接方式变化，两者互不通用：

| 项目 | 2.4G 接收器 | 有线 T88-USB |
| --- | --- | --- |
| VID/PID | `05AC:024F` | `0C45:8006` |
| 配置接口 | Usage Page `0xFF60` / Usage `0x61` | Usage Page `0xFF13` / Usage `0x01` |
| 报文形态 | Input/Output 各 64B，无 Feature | Input/Output 各 64B + Feature 64B |
| macOS 发送 | `SetReport(output, id 0, 64B)` | `SetReport(feature, id 0, 64B)` |
| 回帧 | 固定 `0F 01 01 11` + 全零，合法/非法相同 | 回显收到的帧并附状态字节 |
| 回读 | 无业务数据 | 可 `GetReport(feature)` 取回显 |

有线模式回显（发一帧后立即 `get 0 64` 读回）：

```
04 18 …                      → 04 18 00 01 00 …
04 13 00 … 01 …              → 04 13 00 01 00 … 01 …     ([8]=1 保留)
01 FF 00 00 00 00 00 00 00 05 03 03 00 00 AA 55 …  → 原样回显
04 02 …                      → 04 02 00 01 0A 02 …     (状态字节 0A 02)
04 F0 …                      → 04 F0 00 01 …
04 17 01 …                   → 04 17 01 FF …            ([3]=FF，读请求未受理)
```

`[2]=01` 表示命令被受理；2.4G 通道只有单向确认，无法判断写入是否被采纳。
驱动默认优先 feature 接口（`0xFF13`），仅当设备只有 2.4G 时退回 `0xFF60` 中断 OUT。

## 2. 事务模板

所有命令都是 64 字节裸报文，前两字节为命令码。灯效与参数类命令统一遵循：

```
04 18          握手
04 13 / 04 17  进入配置域 / 查询
64B 数据包     布局见各节
04 02          应用（RAM）
04 F0          写 EEPROM（可选，掉电保留）
```

`04 18` 不做则后续报文无效；`04 02` 不做则只进缓冲不生效。

## 3. 已实现的命令

### 3.1 灯效

```
[0]   mode        1..20（0x80 = 关闭背光）
[1..3] R,G,B
[8]   colortype   0 = 单色模式，1 = 多彩模式
[9]   亮度        1..5
[10]  速度        1..5
[11]  方向        0..3
[14]  0xAA   [15] 0x55
```

序列：`04 18` → `04 13`（`[8]=1`）→ 灯效载荷 → `04 02` →（可选）`04 F0`。
单色模式下 `[1..3]` 取同一色值，多彩模式按模式表自行取色。

### 3.2 设备参数块

序列：`04 18` → `04 17`（`[2]=1 [8]=1`）→ `00 01` 参数块 → `04 02`。

| 偏移 | 含义 |
| --- | --- |
| `[2]` | 复选框 A（布尔开关） |
| `[3]` | 复选框 B（布尔开关） |
| `[4]` | 复选框 C（布尔开关） |
| `[5]` | Fn 层开关 |
| `[6]` | 休眠时间 |
| `[8]` | 按键响应时间 |
| `[12]` | 轮询率 |
| `[13]` | 极速/磁轴模式 |
| `[14]` | 连续快速触发（Rapid Trigger） |
| `[62..63]` | `AA 55` 校验尾 |

`[2][3][4]` 是三个布尔位，不是下拉索引；`[7] [9..11] [15..61]` 保持 0。

### 3.3 逐键灯效

| 命令 | 作用 |
| --- | --- |
| `04 20` | 下发逐键颜色，仅应用 |
| `04 23` | 下发逐键颜色 → `04 02` → `04 F0` 落盘 |
| `04 F5` | 回读逐键颜色 |

头部帧 `[8]` 选择布局与数据块长度：

| `[8]` | 数据块 | 每键字节 | 记录格式 |
| --- | --- | --- | --- |
| `3` | 192 B | 1 | 单标记字节（`0xFD` 单色 / `0xFF` 逐键） |
| `8` | 512 B | 4 | `{键索引, R, G, B}`，最多 128 键 |
| `9` | 576 B | 4 | `{键索引, R, G, B}`，最多 144 键 |

`04 23` 完整序列：`04 18` → `04 23` → 数据块按 64B 一帧顺序下发 → `04 02` → `04 F0`。

## 4. 已知但未实现

以下命令在抓到的报文里出现过，但语义尚未逐条确认，驱动不实现也不猜测：

| 命令 | 推测用途 |
| --- | --- |
| `04 19` + `04 15` | 逐键参数（行程 / 触发点） |
| `04 1C 09` / `04 1C 0B` | 分批上传（第 9 / 11 段） |
| `04 28 [8]=1` | 分区选择 / 进入某配置域 |
| `04 2C [8]=0x0C` | 设备信息 / 全局配置 |
| `04 2D` | 单个开关写入 |
| `04 2E` / `04 2F`、`04 3A` / `04 3B` | 成对命令，疑似请求 / 回读 |
| `04 72` | 自定义灯效 |

对应功能（宏、改键、DKS、磁轴逐键行程、LCD / GIF）需要分段上传结构化数据块，
要逐段比对报文才能定性，目前不在驱动范围内。

## 5. 限制

1. 2.4G 通道无回读，写入是否生效只能以键盘实际行为为准。
2. `04 17` 在有线通道返回 `[3]=FF`，说明读请求未受理，参数块目前只能写不能读。
3. 宏 / LCD 等大块数据需要分帧上传，帧序与校验未验证。
